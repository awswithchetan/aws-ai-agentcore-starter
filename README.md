# Building Production-Grade AI Agents with Amazon Bedrock AgentCore — Starter

This is the **starter repository** for the course _Building Production-Grade AI
Agents with Amazon Bedrock AgentCore_, where you build **Aria**, a
production-grade AI customer support agent.

It contains **Module 00 — Prerequisites** only, so you can set up your local
workstation and AWS account before the course begins. Access to the full course
repository (all remaining modules, the ShopSmart backend, the Aria agent, and
the Streamlit UI) is provided as part of the Udemy course.
